# 🧠 Sentiment Analysis Web App (PyTorch + Streamlit)

##  Overview
This project is a **Sentiment Analysis Web Application** built using **PyTorch** and deployed with **Streamlit**.  
It predicts whether a given text expresses **positive or negative sentiment** in real-time.

---

##  Features
- Real-time text sentiment prediction
- Clean and interactive UI using Streamlit
- PyTorch-based deep learning model
- Efficient text preprocessing using TF-IDF vectorization

---

##  Tech Stack
- Python
- PyTorch
- Scikit-learn
- Streamlit
- NumPy / Pandas
